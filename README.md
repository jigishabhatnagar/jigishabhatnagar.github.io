# Jigisha Bhatnagar Portfolio

Personal portfolio website for [jigishabhatnagar.com](https://jigishabhatnagar.com), built with vanilla JavaScript and GitHub Pages.

This site presents Jigisha Bhatnagar's work across B2B sales, SaaS growth, strategic account management, customer retention, and marketplace growth.

## Content Management

Most visible content is managed in [`config.json`](config.json).

After editing source files, rebuild bundled assets:

```bash
npm run build
```

Then commit and push to publish through GitHub Pages.

## Domain

The site is configured for `jigishabhatnagar.com` through:

- `CNAME` in this repository
- GitHub Pages
- Cloudflare DNS and Worker routing
